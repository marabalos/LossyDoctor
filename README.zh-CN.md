## 首先：什么是 *lossy*（有损音频）

MP3、AAC、Vorbis、Opus 以及其他 *lossy*（有损）格式通过不可逆地丢弃部分音频信息来减小文件体积。

因此，**有损文件绝不应作为母版源、长期保存格式或交换中间格式使用**。再次编码为另一种有损格式，只会增加一代新的损失；转换为无损格式则只会增大文件体积，并不能恢复已经丢失的数据。

然而，大量音乐、录音、广播、bootleg、历史资料以及数字发行内容，**只存在于有损格式中，或实际上只以有损格式流通**。

LossyDoctor 正是为这些情况而设计。

**它面向有损音频收藏，但采用发烧友式的思维和保守的处理方法：最大限度保存仍然存在的真实内容，而不是为了“修复”再次降低其质量。**

## LossyDoctor 是什么？

LossyDoctor 用于审计有损音频文件，检测损坏、结构异常、bitstream（比特流）问题、时间线问题以及解码异常。

它的核心原则非常简单：

> **绝不通过新的有损编码进行修复。**

如果文件能够在保留原始压缩音频的前提下得到修正，LossyDoctor 会生成一个修复副本，并再次验证它。

如果已经无法安全修复原始压缩数据，但仍能精确证明哪些 PCM 是真实且可恢复的，LossyDoctor 可以将其保存为 **FLAC 无损文件**。生成的文件会更大，但不会引入新的损失：它会精确保留这些恢复出的 PCM，使原本无法正常播放的音频重新变得可播放。

原始文件始终保持不变。

## 它能做什么

- 根据文件内容识别格式，而不仅仅依赖扩展名。
- 审计结构、bitstream、时间线和解码行为。
- 即使文件仍能播放，也能检测其中的损坏。
- 只有在存在可证明的修正方案时才进行修复。
- 始终保留原始压缩 bitstream。
- 对每个修复后的文件重新进行验证。
- 当安全修复原始文件已不可能时，可将可证明真实的 PCM 保存为 FLAC。
- 可处理单个文件或完整音频收藏。
- 从不修改或覆盖源文件。

1.1.0 版本在各格式已经证明的处理权限范围内支持 MPEG Layer II/III、AAC/ADTS、单音轨 MP4/AAC、Ogg/Opus、Ogg/Vorbis 和 ASF/WMA。

## 它不会做什么

- **不会把 MP3 重新编码成 MP3、把 AAC 重新编码成 AAC，也不会通过新的有损压缩来“修复”文件。**
- 不会恢复原始编码时已经丢失的音质信息。
- 不会凭空生成或重建无法证明原本存在的音频。
- 不会仅仅因为某个解码器能够播放文件，就认为文件是健康的。
- 不承诺能够修复所有类型的损坏。
- 不会自动把所有有问题的文件转换为 FLAC：只有当原始 bitstream 已无法在不重新编码的情况下正确保存时，才会将无损恢复作为一种保存方案。

## 它可以发现哪些问题？

一个文件可能仍然包含可恢复的音频，但同时存在爆音、卡顿、不完整播放、错误时长、seek（跳转）异常，甚至在某些播放器中完全无法读取。

LossyDoctor 可以检测的情况包括：

- MPEG frame 截断或同步丢失；
- header、Xing/Info 或 VBRI 索引不一致；
- 异常尾随字节或错误 padding；
- CRC 错误；
- Ogg page 损坏或顺序异常；
- timestamp 或连续性问题；
- MP4/AAC 的表、offset 或 duration 错误；
- ADTS header 不一致；
- ASF/WMA packet 或 fragment 不完整。

**发现问题并不意味着一定能够修复。**

当存在唯一且安全的修复方案时，LossyDoctor 可以执行修复。当 bitstream 已无法保留，但仍存在能够证明为真实的 PCM 时，它可以在不引入新一代损失的前提下恢复这些音频。如果两者都无法证明，它会报告损坏，而不会制造一个猜测性的“解决方案”。

## 使用场景

**旧音频收藏**  
审计多年积累、来源各异的成千上万个 MP3、AAC、WMA、Vorbis 或 Opus 文件。

**出现 glitch 的文件**  
判断跳音、中断或播放失败究竟来自可修复的结构异常，还是音频数据本身已经真正丢失。

**已经无法正常播放的文件**  
在存在可证明修复方案时尽量保留原始 bitstream；在极端情况下，抢救仍能被确定为真实的 PCM。

**长期保存**  
在把有损资料纳入永久收藏之前进行验证，同时避免再次经历一代有损压缩。

## 快速比较

| 工具 | 优势 | 与 LossyDoctor 相比 |
| --- | --- | --- |
| **LossyDoctor** | 审计 + 保守修复 + 无损恢复 + 修复后验证 | 支持的格式更少；只在明确支持且经过证明的情况下介入 |
| **MP3val** | 速度快、简单、专注于 MPEG 结构 | 支持格式少得多，对解码和 PCM 证据的分析也更有限 |
| **foobar2000 File Integrity Verifier** | 使用方便，对解码错误检测具有较广泛的格式兼容性 | 对大多数格式而言，检测重点是会导致解码中止的错误；它不是等价的修复与保存系统 |

LossyDoctor 并不追求成为“修改文件数量最多”的修复工具。

它的目标不同：

> **保存有损文件中仍然真实存在的一切内容，而不再引入新一代损失。能够证明修复时才修复；只有当无损恢复是唯一安全方案时才恢复为 lossless；无法确定的内容则不擅自处理。**
